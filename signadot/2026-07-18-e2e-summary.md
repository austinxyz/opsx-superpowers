## Friction found (reported for Joe)

1. **Image allowlist bug** — allowlisted run-container/k6 images still rejected
   ("not in this org's allowed-images list"), incl. k6's own `grafana/k6:1.7.1`.
   Only actionbox-backed actions usable (request-http/eval/check). Org: austinxyza.
2. **No sleep/wait primitive** — async (Kafka) flows need polling; worked around
   with `httpbin.org/delay/4` request-http steps as spacers + 6× retry chain.
   A `wait` action or retry policy on request-http would remove the hack.
3. **No Windows CLI build** — releases are darwin/linux only; source build blocked
   by private `signadot/libconnect`. Docker wrapper works but `auth login` fails
   in-container (dbus keyring); config.yaml fallback works.
4. **Docs 404** — "Enabling Plan Runner Groups" page referenced but missing;
   the dashboard toggle (Platform → Managed Runners) was found by trial.
